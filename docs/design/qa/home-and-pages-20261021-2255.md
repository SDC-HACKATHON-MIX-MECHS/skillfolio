## Deviations found and fixed this pass
- Default-Streamlit leftovers: blue notice boxes, beige text area, beige select (fills sit on inner layers: `stAlertContainer`, `stTextAreaRootElement`, select `role=group`). Now white with a 1px border; errors and warnings carry a left marker.
- Captions rendered at 16px (a generic `p` rule beat the caption size); now 14px.
- AI-impact track was amber (the `amber=True` flag never did anything). Now a neutral grey-brown fill, so it cannot be read as a "good" amber fill.
- Contrast: secondary text on the raised fill was 6.88:1, chip text 5.5-6.9:1. Tokens MUTED `#534E49`, UP_TEXT `#115A38`, DOWN_TEXT `#93251E`. All pairs now >= 7:1.
- Step line on the welcome step was indented 22px from the title; flush now.
- My Portfolio middle KPI label wrapped and dropped its number; shortened to "Hiring trend, 12 months".

## Open items (not fixed, for the user's call)
1. Two different "your skills" trends sit side by side: "+9.7% estimate, next 12 months" (forecast) and "+3.0% in the last 12 months" (past job-post demand). Both are labelled, but a skim could confuse them.
2. In this preview the Fast AI scenario does not change the top-3 order for Aina (it changes the KPI, +9.7% to +19.4%). The handoff expected a #1/#2 swap; that depends on the role data and was not reproduced here.
3. Source captions print raw data names ("job_exposure.csv"): they come from the snapshot's source names, not from UI code.
4. Not checked: keyboard focus ring in the browser, reduced-motion, the open select dropdown (a portal), a returning user's Profile page.
5. The scenario control is a segmented control, not "pills": the brief bans pill buttons.
